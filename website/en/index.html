FAQ

Frequently asked questions

Do I need an electronic drum kit?

No. Keyboard input is always available, although a MIDI kit brings the experience closer to the real instrument.

Does MIDI work on every system?

Not yet. The production backend uses CoreMIDI on macOS; Windows and Linux currently support keyboard gameplay.

Are commercial songs included?

No. The repository contains only original rights-clean music and an example for player-owned local content.

Is this already a stable release?

No. macOS and Windows binaries remain subject to signing, testing, and exact-candidate review before publication.
