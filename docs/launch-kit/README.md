# HitTheKit launch kit

This directory contains reusable, source-only launch material for HitTheKit.
It deliberately makes no claim that a public Unity binary is available and
contains no commercial music, chart, artwork, performer likeness, or third-party
brand asset.

## Ready-to-use copy

- [`linkedin-post.md`](linkedin-post.md) contains English and Italian LinkedIn
  drafts.
- [`community-post.md`](community-post.md) contains a GitHub/community post and
  a shorter Discord, forum, or social variant.

The square image was generated specifically for HitTheKit from project-authored
direction: a fictional modern electronic drum kit, an original cyan/magenta
rhythm highway, a non-identifiable abstract audience, and a dark concert stage.
The prompt explicitly excluded logos, text, real bands, identifiable people,
album art, trademarks, and existing game interfaces. Its authoritative hash is
recorded in [`docs/legal/ASSET_PROVENANCE.sha256`](../legal/ASSET_PROVENANCE.sha256).

## Publishing checklist

1. Use one primary image rather than attaching all variants to the same post.
2. Keep the first two lines focused on the player problem, not the technology.
3. State clearly that the current public release is source-only.
4. Link to the project website or repository, then include the Sponsors link as
   an optional second action.
5. Do not imply endorsement by Unity, Apple, a hardware vendor, or a band.
6. Do not attach player-owned songs, charts, captures, or hardware logs.
7. Answer early comments personally and invite reproducible feedback.
