### HitTheKit is public: feedback wanted on an open-source electronic-drum learning game

HitTheKit is an open-source rhythm game and learning platform built around real
electronic drums. The goal is to help a beginner understand what to hit and
when, then progress through short lessons without requiring traditional music
notation on day one.

The current vertical slice includes:

- a deterministic hit-matching and timing core;
- one shared gameplay session with three original visual environments;
- a beginner curriculum with playable lessons and study speeds;
- guided electronic-kit discovery and mapping;
- keyboard input and macOS Apple Silicon CoreMIDI support; and
- an original rights-clean demo track.

This first public release is intentionally **source-only**. It does not include
an approved Unity player binary, commercial recordings, commercial charts, or
player-owned content.

I would especially value feedback from beginners, drummers using electronic
kits, accessibility reviewers, and developers interested in deterministic
timing or MIDI boundaries. Please use the issue templates and remove serial
numbers, usernames, local paths, and other personal data from hardware reports.

- Website: https://codewriter90x.github.io/HitTheKit/
- Source and good first issues: https://github.com/Codewriter90x/HitTheKit
- Optional sponsorship: https://github.com/sponsors/Codewriter90x

What would make you confident enough to build, test, or contribute to this
project?
