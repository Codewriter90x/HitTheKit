HitTheKit 0.5.0 is the first rights-clean public-release candidate for the
electronic-drum rhythm-game vertical slice. It combines keyboard gameplay,
macOS CoreMIDI input, progressive lessons, guided kit mapping, persistent
settings and progress, and the original `Neon Circuit` demo.

## Highlights

- deterministic hit matching with separate keyboard and MIDI calibration;
- eight readable kit lanes, three original visual environments, scoring,
  combo, pause, restart, diagnostics, and results;
- 12 playable lessons in the first learning semester;
- guided electronic-kit selection, illuminated mapping steps, conflict review,
  and configuration testing;
- macOS Apple Silicon CoreMIDI input with safe keyboard fallback;
- Windows x64 keyboard-only player candidate, subject to clean-machine testing
  and a trusted public-signing decision;
- local player-owned song-pack boundary with no bundled commercial music; and
- privacy, security, licensing, provenance, and community documentation.
