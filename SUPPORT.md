# HitTheKit support

HitTheKit is currently a pre-release community project. Support is best-effort;
there is no guaranteed response time, hardware-compatibility promise, or paid
support contract.

## Before reporting a problem

1. Confirm the version or exact commit you tested.
2. Check the known limitations in [README.md](README.md).
3. Reproduce the issue using the original `Neon Circuit` demo when possible.
4. Remove credentials, personal data, commercial music, and unsanitized MIDI
   captures from logs or attachments.
5. Note the operating system, input type, Unity/build version, and exact steps.

## Where to ask

- **Reproducible bug:** use the GitHub bug-report template.
- **Electronic-drum compatibility:** use the hardware compatibility template.
- **Feature or lesson idea:** use the relevant proposal template.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md) and report it
  privately. Never open a public security issue.
- **Commercial licensing:** the route is not active until legal review and a
  dedicated private contact are complete; see [LICENSING.md](LICENSING.md).

Use GitHub Discussions for general troubleshooting and community questions.
Use the structured issue forms for reproducible bugs, hardware evidence, and
proposals so that actionable reports retain the information needed for review.

## Supported versions

Only the current `0.6.x` pre-release line receives best-effort fixes. Historical
playtest tags and binaries are unsupported and must not be redistributed as
current releases.

## Useful evidence

- a minimal sequence of steps;
- expected and actual behavior;
- a short, sanitized log excerpt;
- whether keyboard input reproduces the issue;
- electronic-kit manufacturer, model, module, connection, and MIDI notes when
  relevant; and
- timing calibration and audio-buffer settings when reporting judgment issues.

Do not upload a full commercial song, chart, recording, credential, private
MIDI capture, crash dump containing personal paths, or signing material.
