# Gameplay visual directions

These mockups are visual-design references for HitTheKit. They are not runtime
screenshots and must not be used as a substitute for real UI components or
gameplay state.

## Selected direction

`gameplay-visual-direction-01-arena-highway.png` is the selected direction.

Its implementation priorities are:

- a wide, central perspective highway connected visually to the drum kit;
- a bright and unambiguous impact line;
- large, glowing, shape-coded note markers;
- compact score, accuracy, combo, and song-progress HUD regions;
- readable drum targets along the bottom edge;
- arena depth, audience silhouettes, and concert lighting without obscuring
  gameplay information.

## Alternatives retained

- `gameplay-visual-direction-02-drummer-cockpit.png` explores a closer drummer
  point of view.
- `gameplay-visual-direction-03-precision-arena.png` explores a cleaner,
  competitive presentation.

All three images are retained so later settings or accessibility variants can
reuse useful ideas without losing the chosen visual baseline.

## Implementation evidence

- `gameplay-visual-implementation-final.png` is a real screenshot of the
  implemented Unity gameplay screen.
- `gameplay-visual-comparison-final.png` places the selected concept and the
  real implementation side by side for visual QA.
